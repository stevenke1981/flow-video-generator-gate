# Google Flow 多帳號輪值

本流程在使用者已要求生成影片時執行。帳號切換已獲使用者授權，不需要每次再確認；生成數量與規格仍以本次任務為限。

## 固定帳號順序

只在本機技能中保留完整帳號識別，任務紀錄使用遮罩或別名。

1. `account-1@example.com`
2. `account-2@example.com`
3. `account-3@example.com`
4. `account-4@example.com`
5. `account-5@example.com`
6. `account-6@example.com`
7. `account-7@example.com`

## 帳號池與進度

1. 沿用已連線的 Chrome 工作階段，從 Flow 帳戶介面核對實際 Google 帳號。任務指定起始帳號時依指示，接續時依進度記錄的帳號繼續，其他情況從固定清單第一個帳號開始。需要輪值時由目前帳號往下走，清單末尾接回第一個。Chrome 設定檔與 Google 帳號分開核對，設定檔名稱只用於定位。
2. 在目前任務的 `work/flow/account-rotation.json` 保存最小進度：帳號別名與足以區別身分的遮罩識別、固定順序、目前游標、餘額與讀取時間、已知重設時間、帳號狀態、各帳號專案連結，以及片段的提交與下載狀態。只保存任務資訊，不保存密碼、cookies、token 或瀏覽器憑證。
3. 每個片段記錄固定片段 ID、提示詞與參考素材路徑、模型／比例／長度／輸出數、使用帳號、專案、job／結果卡連結、狀態及本機輸出位置。接續工作時先讀回進度，再核對 UI；舊紀錄不代表目前餘額。

## 每日與每月額度

- 依 Pro 額度規劃。每天配發 50 點，當天未用完不累積；每月另有 1,000 點，按帳號週期重置，未用完不結轉下月。兩池均全滿時可規劃的合計餘額為 1,050 點。每日點數會再配發，因此月內累計可用的點數須考慮每天實際補發量。送出前核對該帳號的方案、餘額與 Flow 顯示成本，並只執行本次授權的生成。[Google Flow 點數說明](https://support.google.com/flow/answer/16526234?hl=zh-Hant)
- 日期記錄採使用者時區，未另指定為 `Asia/Taipei`。Google 的重設時間以介面可見資訊為準；不能假設台北午夜一定補點。
- 新的一天或到達每日／每月重設時間時，將舊的「耗盡／本片段不足」標記改成待檢查，再讀實際餘額。若點數還沒補發，本輪跳過並記錄。
- 送出前確認本次模型、解析度、長度、輸出數的總成本。餘額未知或成本未知時先查介面，不用試送生成來探測點數。不同付費／免費點數池若有區別，只使用任務允許的額度。

## 切換與提交

1. 讀取目前帳號與餘額。若足夠支付下一片段的完整成本，保留設定並送出一次；餘額為零或小於該成本時，保存狀態並前往固定順序中的下一帳號，最後一個之後回到第一個。
2. 使用網站提供的帳號切換入口；若帳號在不同且已連線的 Chrome 設定檔，使用對應的現有工作階段。切換後重新讀取帳號識別、點數、專案和影片設定，不能只根據頭像或網址中的帳號序號判定成功。不要登出其他帳號或提取憑證搬移登入狀態。
3. 登入失效、驗證碼、2FA 或需要使用者登入的帳號標記為需要處理，跳到其他已登入的可用帳號。帳號停權、服務限制或政策拒絕不是點數不足，不以輪值重試相同被拒工作。所有帳號都需要登入時，保存進度並請使用者處理登入。
4. 專案、角色元件與其他雲端素材可能屬於特定帳號。先查切換後帳號能否存取；不能存取時，在新帳號建立對應專案，用本次任務已授權的提示詞與本機參考素材重建設定。入鏡角色缺少元件時，依 [建立 Flow 角色元件](../SKILL.md#建立-flow-角色元件) 先用核准角色圖建好並確認引用，再提交影片。素材的跨帳號使用範圍不明時，先釐清。
5. 每個片段最多一筆未確認的提交。逾時、頁面錯誤或結果不明時，先回原帳號的專案／生成紀錄確認：已接受或處理中就追蹤原工作；成功就下載；只有確認未建立工作，或確認失敗且符合本次重試授權時，才可再次提交。單獨看到點數不足訊息仍須核對是否已存在該工作。
6. 提交後記錄 job／結果卡並讀回餘額；扣點可能延遲，不用舊餘額連續送出。下載按帳號別名與片段 ID 分別命名或存放，避免覆蓋；需要回原帳號下載時依記錄切回並核對身分。

## 結束條件

- 對同一待辦片段，一輪最多檢查每個帳號一次；全部都不可用或不足時停止，不循環切換、不持續輪詢、不自動購買。保存下一片段與原因，回報各帳號最後可見餘額、已完成數量與剩餘工作。
- 「不足」必須連同所需成本記錄。例如剩 5 點不能做 10 點片段，不代表帳號已歸零；之後使用者授權 4 點工作時可重新評估。
- 要隔天自動續做，必須有使用者另行要求的排程；沒有排程時，下次啟動技能讀回進度並重新查額度。不得把這份操作規則描述成已安裝背景輪值服務。

## 檢查案例

| 情境 | 預期行為 |
|---|---|
| A 剩 0 點，B 剩 50 點，下個片段 10 點 | 自動切 B，讀回帳號／設定，提交一次 |
| A 剩 5 點，下個片段 10 點 | 記錄本片段不足並切換，保留剩 5 點的事實 |
| A 已送出但畫面逾時 | 查 A 的紀錄，尚未確認前不在 B 重送 |
| 所有帳號不足 | 檢查一輪即停止，保存剩餘待辦，不購買 |
| 跨日，但 UI 仍顯示 0 點 | 記錄未補點並跳過，不假造 50 點餘額 |
| 切 B 後找不到 A 的專案 | 建立對應專案並使用已授權素材，重新核對設定 |
| 使用者只要提示詞或詢問 Flow Music | 不執行影片帳號輪值或提交生成 |
